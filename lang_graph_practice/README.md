# Lang Chain

This Project is a basic Agent AI Tool creation using Lang Chain
### Step1:
install all the packages using below command in Terminal

#### pip install -r requirements.txt
### Step2:
1. Create an Open AI API key from available Open AI platform for a LLM.
   1. Open the page https://platform.openai.com/ create your own account.
   2. Go to API keys in the left panel and generate an AI key by clicking on **create new secret key**
   3. Once you generate an API key copy it and save it somewhere.
2. Paste your API key in the .env file with a variable **OPENAI_API_KEY**.
